# Discount Apparel Network, Inc.

Static company-information website for Discount Apparel Network, Inc.

## Deploy with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Open the Pages URL shown by GitHub after deployment.

The site is plain HTML and CSS, so no build command or package installation is required. GitHub Pages will use `index.html` as the home page. The PHP files are retained for other hosting environments and are not used by GitHub Pages.

## Included pages

- `index.html` — company information, About, and Contact sections
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `style.css` — shared responsive styling
